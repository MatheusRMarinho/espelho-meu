# espelho-meu

> **Sistema de agendamento de serviços de beleza**
> Trabalho acadêmico da disciplina de Gerência de Projetos e Manutenção de Software (GPMS).

## Sobre o Projeto
O Espelho Meu é um sistema de agendamento de serviços de beleza destinado a profissionais, clientes e responsáveis administrativos. O sistema pretende automatizar a consulta de horários, o agendamento, o cancelamento, o reagendamento, o envio de notificações e a consulta ao histórico de atendimentos.

O tema possui complexidade suficiente para ser desenvolvido em múltiplas iterações, pois envolve diferentes tipos de usuários, regras de disponibilidade, gerenciamento de agenda, notificações, autenticação e integração futura com pagamentos.
